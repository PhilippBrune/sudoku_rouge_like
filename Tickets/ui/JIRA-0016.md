# JIRA-0016 — Boss Mode UI, Fog Behavior, Killer Cage Fix, Button PNGs & XP Loop

**Created:** 2026-03-09

## Summary

Fix six in-game regressions and add two new features following JIRA-0014/JIRA-0015 completion.

---

## Requirements

### R1 — Boss Mode Description (new feature)
- Add a small description text in the **bottom-right** area of the sudoku gameplay panel.
- Shows the active boss modifier name and a one-line rule explanation when a boss modifier is active.
- Hidden when no boss modifier is active.

### R2 — Arrow Sum: Circle Cell Never Given
- In a new game (not resumed), the **circle (bulb) cell** of every arrow sum constraint must **never** be a pre-filled given.
- The circle is the "sum target"; if it is a given the sum is trivially revealed before solving.

### R3 — Fog of War: Allow Placement, Validate on Reveal
- **Previous behaviour:** placing any number in a fogged cell is blocked entirely.
- **New behaviour:**
  - The player **can** place a number in a fogged cell.
  - The placement is **not validated** (no HP loss) while the cell remains fogged.
  - When the fog over that cell is **revealed** (via correct adjacent placements), the value is checked:
    - Correct → no penalty.
    - Incorrect → normal mistake penalty applied at that moment.

### R4 — Killer Cage NullRef (line 4434)
- `NullReferenceException` in `BuildModifierOverlays` at line 4434: `sumText.text = cage.Sum.ToString()`.
- Root cause: `GetComponent<Text>()` returns null when Text was added via the GameObject constructor.
- Fix: replace constructor-based component add with `AddComponent<Text>()`.
- Same fix applied to SizeLabel / DiffLabel in `CreatePathNodeButton`.

### R5 — Button PNGs from main_menue.png
- Crop each button from `docs/main_menue.png` and save as individual PNG files in `docs/`.
- Button names: Start Game, Resume Game, Tutorial, Meta Progression, Game Modes, Items, Options, Credits, Quit.

### R6 — Main Menu Buttons Transparent
- Main menu button background should be **transparent** (alpha ≈ 0).
- Text and outline/border remain visible.

### R7 — Garden Overview: Rest/Relic/Shop Labels
- Rest, Relic, and Shop nodes in the Garden Overview still do not show the size (top-left) and stars (bottom-right) labels.
- Root cause: same `GetComponent<Text>()` null issue as R4 — text components created via constructor are not found.
- Fix: use `AddComponent<Text>()` for SizeLabel and DiffLabel in `CreatePathNodeButton`.

### R8 — XP Loop per ClassProgressionSystem.md
- Per-class level-up loop in `ClassGardenProgressionService.ApplyRun` uses the wrong upper bound:
  `while (entry.Level < state.CurrentLevel)` should be `while (entry.Level < MaxLevel)`.
- `MetaProgressionPanelController.RefreshView` must display per-class level and XP progress for the selected class.
