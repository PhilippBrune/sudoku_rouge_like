#### Constraint Rules (ConstraintRules.cs)
- `PalindromeRule` — Category=Line, Order=4 — checks cell[j] == cell[n-1-j] mirror value

- `EvenOddRule` — Category=CellLevel, Order=0 — even marker → even digit; odd marker → odd digit
- `NonconsecutiveRule` — Category=GlobalNegative, Order=0 — no orthogonally adjacent consecutive digits

- `GenerateBetweenLines` / `TryBuildBetweenLine` — random walk, interior solution values between endpoints
- `GenerateEvenOddMarkers` — marks N shuffled cells with Even/Odd based on solution parity

#### ModifierFactory (ModifierFactory.cs)

### R4 — Star Difficulty: Clamp Bug Fix

**Problem:** `SudokuGenerator.CreatePuzzle` clamped `removeCount` to `totalCells - size` (e.g., max 72 for 9×9). For 6★ (90% missing = 73 removals on a 9×9), this prevented reaching the target, leaving ≥9 given digits instead of 8.

**Root Cause:**
```csharp
// Line 16 — BUG
var removeCount = Math.Clamp(
    (int)Math.Round(totalCells * missingPercent), 1,
    totalCells - size);  // For 9×9: max 72, but 6★ needs 73
```

**Solution:**
```csharp
var removeCount = Math.Clamp(
    (int)Math.Round(totalCells * missingPercent), 1,
    totalCells - 1);  // Allow up to 80 removals for 9×9
```

**Files:** `Assets/Scripts/Sudoku/SudokuGenerator.cs`

### R5 — Boss Modifier: Save/Resume Serialization

**Problem:** `RunState.ChosenBossModifier` was `BossModifierId?` (nullable) and `SeenBossModifiers` was `HashSet<BossModifierId>` — neither serialize correctly with Unity's `JsonUtility`.

**Solution:**
- Replaced `BossModifierId? ChosenBossModifier` with serialization-friendly `bool HasChosenBossModifier` + `BossModifierId ChosenBossModifierId`, plus a property accessor that provides the same `BossModifierId?` API
- Added `List<BossModifierId> SeenBossModifierList` for serialization
- `SeenBossModifiers` marked `[NonSerialized]` (runtime-only HashSet for fast lookup)
- `SyncSeenModifiersToList()` — call before save; copies HashSet → List
- `SyncSeenModifiersFromList()` — call after load; copies List → HashSet
- `RunAutoSaveCoordinator.Save` calls `SyncSeenModifiersToList()` before building envelope
- `RunResumeService.TryResumeFromSave` restores `HasChosenBossModifier`, `ChosenBossModifierId`, `SeenBossModifiers` from list, and `AllowIrregularPuzzles`

**Files:**
- `Assets/Scripts/Core/RuntimeModels.cs`
- `Assets/Scripts/Save/RunAutoSaveCoordinator.cs`
- `Assets/Scripts/Save/RunResumeService.cs`
