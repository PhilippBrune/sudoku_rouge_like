Class names follow the existing catalogs (for example Number Freak = Maniaque des chiffres / Maniático de los números / Maníaco dos números). Sudoku variant names keep their international names where players know them (Killer, Kropki, Renban, XV) and translate the rest descriptively (Thermometer, Arrow sums, Anti-Knight, Anti-King). Exclusive item and relic notes use the translated class name, for example "(exclusif au Maniaque des chiffres)".
