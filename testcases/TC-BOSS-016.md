# TC-BOSS-016: Handling Linking of Geometries

- **Requirement:** REQ-BOSS-016
- **Type:** Integration
- **Risk:** High
- **Created:** 2026-03-22 12:38:40

## Precondition

A boss encounter has been initiated with some active modifiers and their geometries are linked correctly.

## Steps

1. Start a new game with some active modifiers.
2. Progress through the boss level/puzzle.
3. Verify if all generated geometries for each active modifier are compatible and adhere to constraints of those modifiers.

## Expected Result

All generated geometries should be linked correctly, maintaining compatibility and following constraints as per their associated modifier rules.
