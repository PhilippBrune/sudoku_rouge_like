# TC-CLASS-002: Verify XP and Level Assignment for Garden Monk Class

- **Requirement:** REQ-CLASS-002
- **Type:** Unit
- **Risk:** Low
- **Created:** 2026-03-22 08:52:34

## Precondition

User is in the game with the Garden Monk class selected as default.

## Steps

1. Start a new game and select any other class except Number Freak or Shrine Archivist.
2. Check if an independent XP Counter and Level display are available on screen for the Garden Monk Class.

## Expected Result

There should be an independent XP Counter and Level for the Garden Monk Class, with levels ranging from 1 to 40.
