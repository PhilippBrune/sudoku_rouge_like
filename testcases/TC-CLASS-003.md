# TC-CLASS-003: Verify Shrine Archivist as Default Class

- **Requirement:** REQ-CLASS-003
- **Type:** Unit
- **Risk:** Low
- **Created:** 2026-03-22 08:52:34

## Precondition

User is in the game at main menu and has not selected any class yet.

## Steps

1. Start a new game without selecting a character or class.
2. Check if Shrine Archivist is automatically set as default class after user selection.

## Expected Result

After user makes their first choice, Shrine Archivist should be the default class selected.
