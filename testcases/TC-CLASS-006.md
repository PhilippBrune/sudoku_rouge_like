# TC-CLASS-006: Test Lantern Seer class unlocking through gold collection

- **Requirement:** REQ-CLASS-006
- **Type:** Unit
- **Risk:** Medium
- **Created:** 2026-03-22 08:52:47

## Precondition

The game is started with no classes locked and 0 gold.

## Steps

1. Start the game.
2. Earn some gold by playing the game.
3. Verify that after collecting a specific amount of gold (e.g., 500), the Lantern Seer class should become unlocked.
4. Attempt to select the Lantern Seer character.

## Expected Result

The player should be able to select and start the Lantern Seer class without any issues.
