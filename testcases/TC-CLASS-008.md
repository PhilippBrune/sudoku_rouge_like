# TC-CLASS-008: Test Quiet Cartographer class unlocking through stage completion

- **Requirement:** REQ-CLASS-008
- **Type:** Unit
- **Risk:** High
- **Created:** 2026-03-22 08:52:47

## Precondition

The game is started with no classes locked and a non-advanced variant.

## Steps

1. Start the non-advanced version of the game.
2. Complete an entire stage without using any pencils or losing any HP.
3. Verify that after completing a stage, the Quiet Cartographer class should become unlocked.
4. Attempt to select the Quiet Cartographer character.

## Expected Result

The player should be able to select and start the Quiet Cartographer class without any issues.
