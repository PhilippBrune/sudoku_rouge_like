# TC-CLASS-012: Check if RunEarned_perRun displays total earned in each run

- **Requirement:** REQ-CLASS-013
- **Type:** Integration
- **Risk:** High
- **Created:** 2026-03-22 08:52:59

## Precondition

The game is initialized and has played at least one run

## Steps

1. Start the game and complete a series of levels
2. Navigate to the end-of-run XP Breakdown screen
3. Observe how much was earned from each category (puzzles, rests, bosses, modifiers) in the RunEarned_perRun screen

## Expected Result

An end-of-run XP Breakdown screen displays the total earned in each run, with specific details on how much was earned from each category
