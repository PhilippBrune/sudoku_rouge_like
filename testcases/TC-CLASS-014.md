# TC-CLASS-014: Verify Level Up Animation Displayed at the Correct Time and Location

- **Requirement:** REQ-CLASS-014
- **Type:** Integration
- **Risk:** Medium
- **Created:** 2026-03-22 08:53:12

## Precondition

Game is running with XP earned

## Steps

1. Start a game session without earning any XP
2. Perform several actions to earn XP
3. End the current run
4. Verify if level up animation played at the end of the run screen or game over screen

## Expected Result

Level up animation is displayed at the correct time and location after gaining enough XP.
