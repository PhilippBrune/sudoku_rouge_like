# TC-GENERAL-002: Verify Alternative Constraint Symbols Enabled/Disabled

- **Requirement:** REQ<｜begin▁of▁sentence｜>-UI-007
- **Type:** Manual
- **Risk:** Medium
- **Created:** 2026-03-22 08:52:15

## Precondition

Game is opened with Alternative Constraint Symbols option enabled by default.

## Steps

1. Open the game.
2. Check if the Alternate Constraint Symbols option is enabled by default.
3. Toggle the Alternative Constraint Symbols option on and off.

## Expected Result

When Alternative Constraint Symbols is enabled, grid lines should be represented differently to indicate constraints. When it's disabled, regular grid lines should be used.
