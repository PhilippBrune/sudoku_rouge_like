- **Type:** Integration
- **Risk:** Medium

## Precondition

The player is in Garden Run mode after starting a new game or loading an existing one

## Steps

1. Start a new game or load an existing one and choose "Save & Quit" option
2. Complete the current section of the garden run
3. From the main menu, select to resume the saved game

## Expected Result

The game should resume from where it was left off after saving
