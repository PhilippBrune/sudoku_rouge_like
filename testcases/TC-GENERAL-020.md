- **Requirement:** REQ<｜begin▁of▁sentence｜>RUN-030
- **Type:** Unit
- **Risk:** Medium
- **Created:** 2026-03-22 08:56:24

## Precondition

The game is at least partially loaded and ready to start the "Spirit Trials" mode.

## Steps

1. Start a new game and select "Spirit Trials" from the Game Modes menu.
2. Watch how HP, Pencil, Items and Rerolls are used over time while playing the game in each difficulty tier.

## Expected Result

Resources should be depleted based on the selected difficulty tier.
