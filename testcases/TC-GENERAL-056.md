# TC-GENERAL-056: VerifyItemAndRelicSlotsInTutorialModeAreEmpty

- **Requirement:** REQ<｜begin▁of▁sentence｜>-121
- **Type:** Unit
- **Risk:** Medium
- **Created:** 2026-03-22 12:43:52

## Precondition

Player is in tutorial mode and has items or relics in their inventory.

## Steps

1. Start a new game in tutorial mode.
2. Verify that the item and relic slots are empty.
3. Solve the first puzzle, checking if the player's class's stats have been altered by any effects from these items or relics.

## Expected Result

Item/Relic slots should be functional but remain empty in tutorial mode to allow players to focus on solving puzzles without distractions.
