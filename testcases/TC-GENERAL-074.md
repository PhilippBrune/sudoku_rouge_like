# TC-GENERAL-074: Test Configuration Control in OptionsMenu

- **Requirement:** REQ-GENERAL-009
- **Type:** Unit
- **Risk:** Medium
- **Created:** 2026-03-22 12:46:14

## Precondition

Open the game and go to options menu

## Steps

1. Navigate to "Options" from Main Menu.
2. Change resolution, fullscreen mode, audio volume levels.
3. Save changes and verify if it appears in saved settings.

## Expected Result

Changes are applied correctly and can be saved and loaded without any loss of data or preferences.
