# TC-GENERAL-079: Verify RunStartSequenceSystem displays images in correct order

- **Requirement:** REQ-GENERAL-014
- **Type:** Integration
- **Risk:** High
- **Created:** 2026-03-22 13:47:16

## Precondition

The game is running and the system is ready for testing.

## Steps

1. Start the game.
2. Observe the sequence of displayed images on the RunStartSequenceScreen.
3. Verify that the images are displaying in order from start to finish (e.g., splash screen, title screen).

## Expected Result

The displayed images should be in correct order from start to finish.
