# TC-GENERAL-084: Selecting starting floor in the Calm or Risk route

- **Requirement:** REQ-GENERAL-018
- **Type:** Manual
- **Risk:** Medium
- **Created:** 2026-03-22 13:47:33

## Precondition

The user is presented with a main menu

## Steps

1. Launch the game and navigate to the Main Menu
2. Click on "Play" option
3. Verify that the Floor Selection screen appears, showing two routes - Calm and Risk.

## Expected Result

The user should be able to select their starting floor in either route from the given options.
