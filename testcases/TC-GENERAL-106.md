# TC-GENERAL-106: Isolation from Normal Play

- **Requirement:** REQ<｜begin▁of▁sentence｜>TUTORIAL-181
- **Type:** Integration
- **Risk:** Medium
- **Created:** 2026-03-22 13:52:49

## Precondition

Player is in normal gameplay and not in tutorial mode.

## Steps

1. Start the game from main menu but do not enter tutorial mode.
2. Check if there are any indicators or pop-ups denoting rewards for completion during normal play.
3. Attempt to complete a puzzle or level during normal gameplay.

## Expected Result

There should be no indicator, label, or reward for completion during normal play when in tutorial mode. Normal gameplay progression should not be affected.
