# TC-META-011: Verify ascension system in different classes

- **Requirement:** REQ-META-013
- **Type:** Unit
- **Risk:** Medium
- **Created:** 2026-03-22 13:50:05

## Precondition

The game is running, there are several classes with levels and XP requirements for ascensions.

## Steps

1. Start a new game session for one of the classes that has an ascension progression.
2. Progress through different stages of the level by gaining enough XP.
3. Check the state of the class after achieving each ascension.

## Expected Result

Upon reaching the right XP threshold, a player should be able to ascend from one stage to the next in the class's progression.
