# TC-META-014: Reset Class Levels and Receive Permanent Cosmetic Recognition

- **Requirement:** REQ-META-014
- **Type:** Manual
- **Risk:** High
- **Created:** 2026-03-22 13:50:13

## Precondition

Player is at a class level higher than 1.

## Steps

1. Open the game.
2. Go to "Prestige" menu.
3. Select option to reset class levels and purchase permanent recognition for cost.
4. Verify that class levels have been reset, character has gained required cosmetic recognition and is able to make purchases again without any costs.

## Expected Result

Player should be able to successfully reset their class levels and receive the necessary cosmetic recognition without any errors.
