# TC-RELIC-003: Replace existing items in inventory when full

- **Requirement:** REQ-RELIC-003
- **Type:** Unit
- **Risk:** High
- **Created:** 2026-03-22 08:54:34

## Precondition

A player's inventory is full

## Steps

1. Add a new item to the player's inventory
2. Verify that the system allows the replacement of one existing item with the new item
3. Check if the old item is correctly removed from the inventory

## Expected Result

The expected behavior, which is successfully replacing an item in the inventory when it is full
