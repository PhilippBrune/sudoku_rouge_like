# TC-RELIC-004: Solver tier items have different effects based on rarity

- **Requirement:** REQ-RELIC-005
- **Type:** Unit
- **Risk:** Medium
- **Created:** 2026-03-22 08:54:34

## Precondition

There are solver tier items in the game

## Steps

1. Observe the effect of an item from a solver tier category
2. Check if there is any difference in its effect when it has different rarities
3. Use this item and check the outcome on solving puzzles or achieving certain objectives
4. Verify that the system correctly identifies and applies the appropriate effect based on the rarity level of the item

## Expected Result

The expected behavior, which is every solver tier item having a unique effect based on its rarity
