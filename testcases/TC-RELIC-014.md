# TC-RELIC-014: Test ItemsAndRelicsSystem

- **Requirement:** REQ-RELIC-015
- **Type:** Unit
- **Risk:** High
- **Created:** 2026-03-22 13:49:05

## Precondition

The game is running and the user has selected a difficulty level.

## Steps

1. Launch the game.
2. Select a difficulty level from the main menu.
3. Navigate to a reward screen with different star ratings.
4. Pick up an item of choice from one of the displayed rewards.
5. Verify that the selected item is now available in the inventory or on the character's equipment slot depending on its type.

## Expected Result

The game should display items based on chosen difficulty and allow users to select, pickup, and place them correctly into their inventory/equipment slots.
