# TC-RELIC-020: Test Item Usage Rules

- **Requirement:** REQ-RELIC-020
- **Type:** Unit
- **Risk:** Medium
- **Created:** 2026-03-22 13:49:22

## Precondition

Player has acquired an item and it's in the grid cell where a puzzle is placed.

## Steps

1. Place a puzzle piece on a grid cell that requires this item type.
2. Use the item by clicking on the same grid cell twice.
3. Verify that the puzzle gets solved correctly with the usage of the item.

## Expected Result

The system should correctly apply the rules for solving puzzles using consumables.
