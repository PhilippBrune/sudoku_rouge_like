# TC-RELIC-025: Test Relics Usage and Feedback Mechanisms

- **Requirement:** REQ-RELIC-026
- **Type:** Integration
- **Risk:** High
- **Created:** 2026-03-22 13:49:47

## Precondition

Player has a specific relic and an item that the relic can interact with.

## Steps

1. Use a specific relic on an item.
2. Check if the relic provides visual feedback based on its type.
3. Verify whether the result of using the relic is as expected (for example, increases stats or changes behaviour)

## Expected Result

When used on an item, it should provide visual feedback and alter the item's properties in accordance with that specific relic.
