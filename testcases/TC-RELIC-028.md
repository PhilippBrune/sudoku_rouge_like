# TC-RELIC-028: Verify the visual cues for safe cell placement and number placement in adjacent cells

- **Requirement:** REQ-RELIC-028
- **Type:** Unit
- **Risk:** High
- **Created:** 2026-03-22 13:50:05

## Precondition

The game is running and a player has started a new game session.

## Steps

1. Start a new game session.
2. Place numbers on some of the cells to create a grid.
3. Try to place another number in an adjacent cell or safe cell.

## Expected Result

A visual cue indicating whether the placement is allowed (e.g., color change, tooltip display).
