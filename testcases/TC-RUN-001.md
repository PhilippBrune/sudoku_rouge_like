# TC-RUN-001: Verify Unlock Condition of Endless Zen Mode

- **Requirement:** REQ-RUN-001
- **Type:** Unit
- **Risk:** High
- **Created:** 2026-03-22 08:53:12

## Precondition

Game is running with an action earning XP to reach Level 40

## Steps

1. Start a game session at level 39 without earning any XP
2. Earn enough XP to reach Level 40
3. Verify if the Endless Zen Mode is unlocked in the game settings

## Expected Result

The Endless Zen Mode is unlocked after reaching Level 40 and earning enough XP.
