# TC-RUN-003: Test Depth Progression and Star Scaling in Endless Zen Mode

- **Requirement:** REQ-RUN-003
- **Type:** Integration
- **Risk:** Medium
- **Created:** 2026-03-22 08:53:25

## Precondition

The player has entered the endless zen mode

## Steps

1. Start a new game in endless zen mode
2. Play for multiple levels to see if depth progression and star scaling are correct
3. Check the UI elements showing the current level, stars collected and depth reached

## Expected Result

Depth should increase with each completed level; Stars should be awarded based on difficulty of each level; Levels should be generated dynamically
