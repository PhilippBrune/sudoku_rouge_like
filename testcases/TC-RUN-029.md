# TC-RUN-029: Verify Steam Workshop Leaderboard Integration

- **Requirement:** REQ-RUN-029
- **Type:** Integration
- **Risk:** High
- **Created:** 2026-03-22 08:56:24

## Precondition

Player has an active steam account linked with the game.

## Steps

1. Launch the game and sign in to a valid Steam user account.
2. Navigate to the "Leaderboards" tab on the main menu screen.
3. Verify that global leaderboard scores are displayed correctly.

## Expected Result

Player's high score should be visible at the top of the leaderboard, ordered by highest first.
