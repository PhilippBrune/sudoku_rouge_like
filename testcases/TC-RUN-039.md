# TC-RUN-039: Test Steam Workshop Leaderboards Integration

- **Requirement:** REQ-RUN-039
- **Type:** Manual
- **Risk:** Medium
- **Created:** 2026-03-22 08:56:33

## Precondition

User is registered with the system and installed the game on their Steam platform.

## Steps

1. Launch the game from Steam.
2. Navigate to the "Achievements" tab in the main menu.
3. Select a leaderboard of choice, for example "Global Leaderboard".
4. Verify if global rankings are correctly displayed and updated by other players.

## Expected Result

User should be able to see global rankings on selected Steam Workshop leaderboards.
