# TC-RUN-069: Verify if a valid number can be placed in an empty cell

- **Requirement:** REQ-RUN-069
- **Type:** Unit
- **Risk:** Medium
- **Created:** 2026-03-22 12:40:52

## Precondition

A blank 3x3 sudoku board is visible on the screen

## Steps

1. Click on one of the cells and check if it becomes highlighted upon clicking
2. Enter any digit from 1 to 9 in the selected cell
3. Check if the number entered replaces the placeholder text in the same cell

## Expected Result

A sudoku board where a valid number can be successfully placed in an empty cell
