# TC-SAVE-006: Check if Garden Run mode supports save and resume functionality

- **Requirement:** REQ-SAVE-006
- **Type:** Unit
- **Risk:** Low
- **Created:** 2026-03-22 08:55:34

## Precondition

The game is running in Garden Run mode

## Steps

1. Open the application
2. Start a new game or load an existing one
3. Verify if "Save & Quit" option is available for saving the game state

## Expected Result

Save and Resume options should be visible and functional
