# TC-SAVE-012: Test Mode-Based Save Support Implementation

- **Requirement:** REQ-SAVE-013
- **Type:** Unit
- **Risk:** Medium
- **Created:** 2026-03-22 08:55:48

## Precondition

System is running without mode-based save support implemented.

## Steps

1. Start a new game session for each supported game mode (Garden Run, Survival etc.).
2. Complete different types of challenges within the game modes to generate progression in the games.
3. Verify that Save and Quit options are available during these sessions.

## Expected Result

Game modes that support profile save and run resume should have the ability to initiate save and quit operations.
