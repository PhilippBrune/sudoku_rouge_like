# TC-SAVE-016: Verify Saved Game Data Lifecycle Management

- **Requirement:** REQ-SAVE-016
- **Type:** Unit
- **Risk:** Medium
- **Created:** 2026-03-22 08:55:59

## Precondition

The game is installed for the first time.

## Steps

1. Launch the game and verify if a new save file has been created.
2. Play through one round of the game.
3. Verify that changes in the game state have been correctly recorded.

## Expected Result

A new save file is created, and changes are correctly recorded after each run.
