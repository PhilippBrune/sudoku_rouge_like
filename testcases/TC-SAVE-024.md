# TC-SAVE-024: Test Garden Run Mode Save and Quit Option

- **Requirement:** REQ-SAVE-025
- **Type:** Unit
- **Risk:** Medium
- **Created:** 2026-03-22 13:50:58

## Precondition

In Garden Run mode.

## Steps

1. Complete a level in Garden Run mode.
2. Press 'Esc' to open pause menu.
3. Click on the 'Save & Quit' option from the pause menu.

## Expected Result

The game saves progress and returns to main menu without crashing or error.
