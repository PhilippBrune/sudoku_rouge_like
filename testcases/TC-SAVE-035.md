# TC-SAVE-035: Save and Quit Option in Garden Overview Pause Menu Test Case

- **Requirement:** REQ-SAVE-036
- **Type:** Unit
- **Risk:** Low
- **Created:** 2026-03-22 13:51:28

## Precondition

User is paused in the garden overview pause menu.

## Steps

1. In the garden overview pause menu, press 'Save & Quit to Main Menu'.
2. Return back to main menu from where user can resume playing the game after closing the current level.

## Expected Result

The player should be able to save and quit while in the garden overview pause menu without losing any progress or stats.
