# TC-SHOP-010: Testing the Economy Balance Targets for Each Floor Level

- **Requirement:** REQ-SHOP-010
- **Type:** Integration
- **Risk:** High
- **Created:** 2026-03-22 08:54:09

## Precondition

Game is running on different floor levels and gold balance targets are defined.

## Steps

1. Play a few runs of the game on various floor levels.
2. Check the average number of gold earned per run for each floor level.
3. Verify that these averages fall within the predefined balance targets.

## Expected Result

The average amount of gold earned per run should be consistent and within the defined balance targets, indicating a successful economy balance target achievement across different floor levels.
