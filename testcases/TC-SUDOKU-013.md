# TC-SUDOKU-013: Create a new game from the main menu

- **Requirement:** REQ-SUDOKU-013
- **Type:** Manual
- **Risk:** High
- **Created:** 2026-03-22 08:57:25

## Precondition

User is on the main menu

## Steps

1. Click on the "New Game" button
2. Select the difficulty level (Easy, Medium, Hard)
3. Press the "Start" button

## Expected Result

A new Sudoku grid appears at the bottom of the screen
