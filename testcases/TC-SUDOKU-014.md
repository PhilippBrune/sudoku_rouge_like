# TC-SUDOKU-014: Select a valid number for cells in the grid

- **Requirement:** REQ-SUDOKU-014
- **Type:** Manual
- **Risk:** Medium
- **Created:** 2026-03-22 08:57:25

## Precondition

User is in game play and has not yet solved the puzzle

## Steps

1. Click on an empty cell in the Sudoku grid
2. Type or select a digit from 1-9 (the number key pad)
3. Press Enter or tap on the selected digit again to confirm

## Expected Result

The digit appears as the value of that cell and cannot be changed
