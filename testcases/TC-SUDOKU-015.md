# TC-SUDOKU-015: Unsuccessful input should clear current cell

- **Requirement:** REQ-SUDOKU-015
- **Type:** Manual
- **Risk:** Low
- **Created:** 2026-03-22 08:57:25

## Precondition

User has just tried to place an invalid number into a cell

## Steps

1. Click on a cell and enter an invalid digit (e.g., 0 or 10)
2. Press Enter/Return key

## Expected Result

The value of the cell should be cleared, i.e., it should return to being empty
