# TC-SUDOKU-016: Pause and resume game from menu option

- **Requirement:** REQ-SUDOKU-016
- **Type:** Manual
- **Risk:** Medium
- **Created:** 2026-03-22 08:57:25

## Precondition

The user is playing a game

## Steps

1. From the main menu, select "Pause"
2. When paused, press Escape or click on "Resume Game" in the menu

## Expected Result

The game continues where it left off (with the same state of the grid), and the timer should resume counting up from when it was last stopped
