# TC-SUDOKU-037: Highlighting Incorrect Entries when Wrong Answer Provided

- **Requirement:** REQ-SUDOKU-037
- **Type:** Manual
- **Risk:** Low
- **Created:** 2026-03-22 11:35:48

## Precondition

A game is in progress and user enters an incorrect answer.

## Steps

1. Enter a wrong solution to a Sudoku puzzle.
2. Observe the highlight of cells that show the error.

## Expected Result

Cells with the incorrectly entered number should be highlighted, providing visual feedback for users to rectify their mistake.
