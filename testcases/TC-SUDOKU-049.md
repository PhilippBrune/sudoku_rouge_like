# TC-SUDOKU-049: Check if a number is valid for a given position

- **Requirement:** REQ-SUDOKU-049
- **Type:** Unit
- **Risk:** Medium
- **Created:** 2026-03-22 11:36:27

## Precondition

A Sudoku board exists and an empty cell on it

## Steps

1. Call the function 'isValid(x, y, num)' with some parameters 
2. Verify if it returns true or false based on the number's validity in the given position  
3. Assert that the returned value matches our expectations

## Expected Result

A boolean indicating whether the number is valid at the provided position or not
