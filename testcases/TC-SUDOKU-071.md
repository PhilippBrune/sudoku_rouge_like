# TC-SUDOKU-071: Check if clicking on a filled cell clears its value

- **Requirement:** REQ-SUDOKU-071
- **Type:** Manual
- **Risk:** Low
- **Created:** 2026-03-22 11:37:19

## Precondition

Game object exists in the scene and game board is initialized with numbers

## Steps

1. Click on one of the cells that has been preloaded with numbers
2. Observe the state of the selected cell before clicking
3. Click again to clear its value

## Expected Result

The selected cell should be empty after clearing its value
