# TC-TUTORIAL-001: Disable Run Progression, Items and Path System when starting Tutorial mode.

- **Requirement:** REQ-TUTORIAL-002
- **Type:** Unit
- **Risk:** High
- **Created:** 2026-03-22 11:37:23

## Precondition

The game is in tutorial mode

## Steps

1. Start the game in tutorial mode.
2. Verify that run progression, items and path system are disabled.
3. Verify that only Sudoku engine operations are enabled.

## Expected Result

RunProgression, Items and Path System should be disabled and only Sudoku Engine operations should be enabled when starting the game in tutorial mode.
