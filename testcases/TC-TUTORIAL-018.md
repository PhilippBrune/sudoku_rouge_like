# TC-TUTORIAL-018: UIManager Updates Based on TutorialSetupConfig Object

- **Requirement:** REQ-TUTORIAL-018
- **Type:** Unit
- **Risk:** High
- **Created:** 2026-03-22 11:37:59

## Precondition

The game is running and a user has selected tutorial mode from the main menu.

## Steps

1. Launch the game.
2. From the main menu, select "Tutorial Mode".
3. Verify that the UIManager updates based on TutorialSetupConfig object by checking if dropdowns for board/stars/class/region selection and 15 modifier toggles are correctly updated.

## Expected Result

The UIManager UI elements should accurately reflect settings defined in TutorialSetupConfig object.
