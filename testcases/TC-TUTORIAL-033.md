# TC-TUTORIAL-033: Persistent Data Storage Test Case for Tutorial Progress per profile

- **Requirement:** REQ-TUTORIAL-033
- **Type:** Unit
- **Risk:** Medium
- **Created:** 2026-03-22 11:38:36

## Precondition

A new user has been created.

## Steps

1. Create a new profile and login into the game using this profile.
2. Complete some tutorial levels.
3. Save and quit from the game.
4. Restart the game and load the previous profile.

## Expected Result

The progress of previously completed tutorials is still intact after restarting the game.
