# TC-TUTORIAL-035: Linked Systems Test Case for Referencing Actual Service/Controller Names

- **Requirement:** REQ-TUTORIAL-037
- **Type:** Integration
- **Risk:** Medium
- **Created:** 2026-03-22 11:38:36

## Precondition

A new requirement has been linked to existing services and controllers.

## Steps

1. Implement a new feature that interacts with an external service or controller.
2. Verify if the implementation is correctly referencing the actual service/controller names in its codebase.

## Expected Result

The implemented feature works as expected when used along with other features linked to the referenced services and controllers.
