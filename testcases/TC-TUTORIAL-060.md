# TC-TUTORIAL-060: Persistent Tutorial Progress Per Profile

- **Requirement:** REQ-TUTORIAL-060
- **Type:** Unit
- **Risk:** Medium
- **Created:** 2026-03-22 11:39:27

## Precondition

User has completed a tutorial run

## Steps

1. Save the progress of a user during a tutorial run in ProfileService
2. Load this data on next run of tutorial

## Expected Result

The saved and loaded tutorial progress is persistent for every profile
