# TC-TUTORIAL-069: RunDirector disables non-puzzle features during tutorial mode

- **Requirement:** REQ-TUTORIAL-068
- **Type:** Unit
- **Risk:** Low
- **Created:** 2026-03-22 11:39:45

## Precondition

Game is running in tutorial mode

## Steps

1. Start the game and switch to tutorial mode
2. Check that all non-puzzle related features are disabled, such as progression, items, path system etc.
3. Solve a puzzle within the tutorial

## Expected Result

Only puzzle related features (like puzzle solving) should remain active during this process
