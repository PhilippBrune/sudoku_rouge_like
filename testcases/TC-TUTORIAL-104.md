# TC-TUTORIAL-104: Test Progress Persistence Across Sessions

- **Requirement:** REQ-TUTORIAL-104
- **Type:** Integration
- **Risk:** High
- **Created:** 2026-03-22 12:43:07

## Precondition

The player has started a tutorial and made some progress.

## Steps

1. Start the game and navigate to the tutorial section.
2. Make progress through the tutorial.
3. Close the game, then reopen it.
4. Verify if the tutorial progress is still intact or not.

## Expected Result

The tutorial progress should be persisted across different sessions so that players can revisit their progress anytime.
