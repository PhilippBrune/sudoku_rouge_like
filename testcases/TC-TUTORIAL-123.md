# TC-TUTORIAL-123: VerifyClassProgressionIsDisabledInTutorialMode

- **Requirement:** REQ-TUTORIAL-123
- **Type:** Unit
- **Risk:** Medium
- **Created:** 2026-03-22 12:43:52

## Precondition

Player is in tutorial mode and has leveled up their class.

## Steps

1. Start a new game in tutorial mode.
2. Solve puzzles to gain experience points.
3. Verify that the player's class progression is not affected by this tutorial mode.

## Expected Result

Class levels should not increase or prestige should not occur, as class leveling and prestige are disabled during the tutorial mode.
