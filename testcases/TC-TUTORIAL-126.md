- **Requirement:** REQ-TUTORIAL-125

User is in tutorial mode and has completed at least one puzzle.

## Steps

1. Start a new game in tutorial mode.
2. Complete at least one puzzle.
3. Check the progress display.

## Expected Result

The progress display shows the completed board sizes and star ratings for the puzzles attempted.
