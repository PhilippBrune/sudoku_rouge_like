# TC-TUTORIAL-131: ProgressPersistence in Different Configurations

- **Requirement:** REQ-TUTORIAL-130
- **Type:** Unit
- **Risk:** Medium
- **Created:** 2026-03-22 12:44:18

## Precondition

User has played the game with different configurations.

## Steps

1. Play the game and complete a puzzle within the tutorial mode, save the progress.
2. Close the application and open it again.
3. Verify if the progress is still there.

## Expected Result

Progress should persist across sessions.
