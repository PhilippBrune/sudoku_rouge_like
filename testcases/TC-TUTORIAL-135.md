# TC-TUTORIAL-135: UIIndicatorLabel in Tutorial Mode

- **Requirement:** REQ-TUTORIAL-134
- **Type:** Unit
- **Risk:** Low
- **Created:** 2026-03-22 12:44:18

## Precondition

User has entered the game and is not in tutorial mode.

## Steps

1. Ensure you are not in the tutorial mode, check if there's a label showing "TUTORIAL MODE".
2. Enter the tutorial mode by navigating to it from the main menu.
3. Verify if there is now a persistent label saying "TUTORIAL MODE" at the top of the screen.

## Expected Result

A persistent label should appear displaying "TUTORIAL MODE", indicating that the user is in tutorial mode.
