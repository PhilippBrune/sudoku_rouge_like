- **Requirement:** REQ-TUTORIAL-137
- **Type:** Unit
- **Risk:** High
- **Created:** 2026-03-22 12:44:31

## Precondition

The game is in tutorial mode.

## Steps

1. Open the game and navigate to the tutorial level.
2. Check if item and relic slots are empty from a player's selected class.
3. Verify that these slots remain functional but cannot be used for any purpose.

## Expected Result

The item/relic slots in tutorial mode do not respond or cause errors when accessed, they can still serve as placeholders.
