# TC-TUTORIAL-138: ProgressPersistenceInTutorialModeTest

- **Requirement:** REQ-TUTORIAL-138
- **Type:** Integration
- **Risk:** Medium
- **Created:** 2026-03-22 12:44:31

## Precondition

The game is in tutorial mode and a puzzle has been completed.

## Steps

1. Open the game and navigate to the tutorial level.
2. Complete a new puzzle in tutorial.
3. Close the application and reopen it.
4. Check if the progress of completing different configurations persists across sessions.

## Expected Result

The progress is saved even after closing and opening the application, the same tutorial level should be accessible again.
