# TC-TUTORIAL-139: ClassProgressionDisablingInTutorialModeTest

- **Requirement:** REQ-TUTORIAL-139
- **Type:** Unit
- **Risk:** Low
- **Created:** 2026-03-22 12:44:31

## Precondition

The game is in tutorial mode and there are active class leveling or prestige mechanics.

## Steps

1. Open the game and navigate to the tutorial level.
2. Verify that no popups related to class progression show up during tutorial mode.
3. Check if any changes in stats or levels occur after reaching a certain point in tutorial.

## Expected Result

No class leveling or prestige mechanics are triggered while playing the tutorial, the stats and levels should not change as they would when playing regularly without tutorial mode.
