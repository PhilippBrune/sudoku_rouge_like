# TC-TUTORIAL-147: Check progress persistence in tutorial mode

- **Requirement:** REQ-TUTORIAL-146
- **Type:** Integration
- **Risk:** High
- **Created:** 2026-03-22 12:44:54

## Precondition

Player has completed a level/puzzle in the tutorial mode

## Steps

1. Start a new game and select a class
2. Complete a level or puzzle in the tutorial mode
3. Close the application and reopen it
4. Verify if the progress is still there

## Expected Result

Progress should persist across sessions
