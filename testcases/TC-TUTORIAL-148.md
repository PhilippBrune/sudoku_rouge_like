# TC-TUTORIAL-148: Verify mistake behaviour in Free resource mode

- **Requirement:** REQ-TUTORIAL-148
- **Type:** Unit
- **Risk:** Medium
- **Created:** 2026-03-22 12:44:54

## Precondition

Player is in Free resource mode

## Steps

1. Start a new game and select a class
2. Try to solve a puzzle without making mistakes
3. Verify if the UI shows that mistake penalty/costs are disabled

## Expected Result

Mistakes should not have any cost or penalty in Free resource mode
