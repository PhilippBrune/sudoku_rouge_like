# TC-TUTORIAL-152: Free Resource Mode in Tutorial Mode

- **Requirement:** REQ-TUTORIAL-152
- **Type:** Manual
- **Risk:** Medium
- **Created:** 2026-03-22 12:45:07

## Precondition

User is in tutorial mode and has selected a class that allows for free resource usage.

## Steps

1. Open the game and start a new tutorial session using a class that provides free resources.
2. Attempt to use these resources on puzzles.

## Expected Result

Free resource usage should not result in penalties or restrictions, as it is meant specifically for practicing Sudoku rules.
