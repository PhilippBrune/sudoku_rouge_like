# TC-TUTORIAL-156: Check if Class Progression is Disabled in Tutorial Mode

- **Requirement:** REQ-TUTORIAL-155
- **Type:** Unit
- **Risk:** Low
- **Created:** 2026-03-22 12:45:20

## Precondition

Game is running in tutorial mode.

## Steps

1. Start a new game in tutorial mode.
2. Attempt to advance to the next class level or prestige.
3. Verify that these actions do not affect the game state or any error messages are displayed.

## Expected Result

No changes to game state and no errors are shown when trying to advance levels or prestiges during tutorial mode.
