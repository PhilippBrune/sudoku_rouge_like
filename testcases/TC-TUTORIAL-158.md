# TC-TUTORIAL-158: Verify Tutorial Mode Indicator Label Appearance

- **Requirement:** REQ-TUTORIAL-158
- **Type:** Unit
- **Risk:** Low
- **Created:** 2026-03-22 12:45:20

## Precondition

Game is running in any mode except tutorial mode.

## Steps

1. Start a new game not in tutorial mode.
2. Check if the persistent label displaying "TUTORIAL MODE" appears on the screen.

## Expected Result

A persistent label with the text "TUTORIAL MODE" should appear on the screen when the game is running in tutorial mode.
