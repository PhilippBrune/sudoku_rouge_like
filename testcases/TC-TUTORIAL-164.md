# TC-TUTORIAL-164: TestMistakeBehaviourInFreeResourceMode

- **Requirement:** REQ-TUTORIAL-164
- **Type:** Unit
- **Risk:** Low
- **Created:** 2026-03-22 12:45:32

## Precondition

Player is in tutorial mode with Free Resource Mode enabled.

## Steps

1. Start a new game in Free Resource Mode.
2. Make a mistake while solving the Sudoku puzzles.
3. Verify that mistakes do not incur any cost or penalty.

## Expected Result

Players should be able to make mistakes without any penalties or costs in this mode, encouraging them to understand and practice the rules correctly.
