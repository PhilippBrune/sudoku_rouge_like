# TC-TUTORIAL-177: Test Star Difficulty Levels Functionality

- **Requirement:** REQ-TUTORIAL-175
- **Type:** Unit
- **Risk:** High
- **Created:** 2026-03-22 13:52:21

## Precondition

User is on the settings page of the game.

## Steps

1. Navigate to the "Game Settings".
2. Check if there are options for setting difficulty levels with varying percentages of pre-filled cells.
3. Set the difficulty level to easy (10% missing) and expert (almost no given numbers).
4. Start a new game using these settings.

## Expected Result

The game board should have 10% missing numbers on the easy level, almost no given numbers on the expert level.
