# TC-TUTORIAL-178: Test Resource Mode Functionality

- **Requirement:** REQ-TUTORIAL-177
- **Type:** Unit
- **Risk:** Medium
- **Created:** 2026-03-22 13:52:21

## Precondition

User is on the settings page of the game.

## Steps

1. Navigate to the "Game Settings".
2. Check if there are options for setting resource modes: Free and Class-Based.
3. Select different resource modes (Free, Class-Based) and start a new game using these settings.

## Expected Result

The game should allow selecting between free mode(no progression penalties) or class-based mode. In the latter case, it should use selected class's stats to adjust difficulty level.
