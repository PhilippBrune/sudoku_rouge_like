# TC-TUTORIAL-179: Test Region Layout Variants Functionality

- **Requirement:** REQ-TUTORIAL-178
- **Type:** Unit
- **Risk:** Low
- **Created:** 2026-03-22 13:52:21

## Precondition

User is on the settings page of the game.

## Steps

1. Navigate to the "Game Settings".
2. Check if there are options for selecting different region layout variants like standard rectangular regions, alternative shapes or jigsaw-like layouts.
3. Select and start a new game using each available option.

## Expected Result

The game should allow selecting between various region layout variants. Each variant should affect the way cells are distributed on the board.
