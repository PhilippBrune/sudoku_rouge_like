# TC-TUTORIAL-182: UI Indicator for Tutorial Mode Active

- **Requirement:** REQ-TUTORIAL-180
- **Type:** Unit
- **Risk:** Low
- **Created:** 2026-03-22 13:52:49

## Precondition

Player is in tutorial mode and game starts.

## Steps

1. Start the game from main menu.
2. Verify if a persistent label indicating that tutorial mode is active appears at the top of the screen.
3. Check if there are any indicators or pop-ups denoting rewards for completion during tutorial play.

## Expected Result

UI Label should be visible and accurate, no reward indicators should appear during tutorial play.
