# TC-TUTORIAL-183: Disabled Elements in Tutorial Mode

- **Requirement:** REQ-TUTORIAL-182
- **Type:** Unit
- **Risk:** High
- **Created:** 2026-03-22 13:52:49

## Precondition

Player is in tutorial mode and starts a new game from the main menu.

## Steps

1. Start a new game from main menu and enter into tutorial mode.
2. Attempt to progress through the tutorial, attempt earning XP, acquire items or complete levels.
3. Check if all progression elements are disabled in tutorial mode.

## Expected Result

No XP should be earned, no item should be acquired, no level should be completed during tutorial play and no class unlocking progression should occur. All actions should remain restricted to the guidelines provided by the tutorial.
