# TC-TUTORIAL-185: Progress Views for Tutorial Mode

- **Requirement:** REQ-TUTORIAL-184
- **Type:** Integration
- **Risk:** High
- **Created:** 2026-03-22 13:52:49

## Precondition

Player starts a new game from the main menu and enters into tutorial mode.

## Steps

1. Start a new game from main menu and enter into tutorial mode.
2. Attempt to complete a puzzle or level during tutorial play, use up resources if needed.
3. Check if progress views are provided for board × star rating combinations attempted, individual modifier training progression, and overall completion percentage.

## Expected Result

Progress views should be visible and accurate showing the attempts at different combinations of boards and stars, the progress in modifiers used during tutorial play, and an overall indication of how much has been completed by the player.
