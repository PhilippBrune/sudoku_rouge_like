# TC-TUTORIAL-190: Board Size Selection Test

- **Requirement:** REQ-TUTORIAL-189
- **Type:** Integration
- **Risk:** Medium
- **Created:** 2026-03-22 13:53:12

## Precondition

Player is at tutorial mode

## Steps

1. Start a new game session in tutorial mode
2. Select different board sizes (5×5, 6×6, 7×7, 8×8 and 9×9) from the dropdown menu
3. Verify if the selected board size is reflected correctly on-screen and used for the game

## Expected Result

The system should provide a dropdown menu for selecting different board sizes which will be reflected in the UI and can be used by the player to play games with these specific dimensions.
