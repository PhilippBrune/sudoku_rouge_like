# TC-TUTORIAL-192: Setting difficulty levels with varying percentages of pre-filled cells

- **Requirement:** REQ-TUTORIAL-190
- **Type:** Unit
- **Risk:** Medium
- **Created:** 2026-03-22 13:53:38

## Precondition

The system is launched and the game grid is visible.

## Steps

1. Navigate to the settings menu in the main menu.
2. In the dropdown for difficulty level, select a value between easy (10% missing) to expert (almost no given numbers). 
3. Verify that only cells corresponding to the selected percentage have been filled in.

## Expected Result

Only the specified proportion of cells are pre-filled with numbers.
