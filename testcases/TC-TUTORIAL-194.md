# TC-TUTORIAL-194: Providing two resource modes: Free and Class-Based

- **Requirement:** REQ-TUTORIAL-192
- **Type:** Unit
- **Risk:** Medium
- **Created:** 2026-03-22 13:53:38

## Precondition

The system is launched with game grid visible.

## Steps

1. Navigate to the settings menu in the main menu.
2. Verify that options for resource mode are present - Free and Class-Based.
3. Change the resource mode by clicking on them.

## Expected Result

The game progression should be disabled or enabled as per user choice.
