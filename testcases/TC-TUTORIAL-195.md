# TC-TUTORIAL-195: Allowing selection between standard rectangular regions, alternative shapes and jigsaw-like layouts

- **Requirement:** REQ-TUTORIAL-193
- **Type:** Unit
- **Risk:** High
- **Created:** 2026-03-22 13:53:38

## Precondition

The system is launched with game grid visible.

## Steps

1. Navigate to the settings menu in the main menu.
2. Verify that options for different Sudoku grids are present - standard rectangular regions, alternative shapes or jigsaw-like layouts.
3. Change the game layout by selecting a new one from the dropdown.

## Expected Result

The selected layout of the grid should appear on the screen with no cell values visible initially.
