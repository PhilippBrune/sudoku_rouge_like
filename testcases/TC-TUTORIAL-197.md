# TC-TUTORIAL-197: Verify tutorial mode active indicator is displayed

- **Requirement:** REQ-TUTORIAL-195
- **Type:** Unit
- **Risk:** Low
- **Created:** 2026-03-22 13:54:03

## Precondition

Game starts

## Steps

1. Launch the game
2. Observe if a persistent label indicating tutorial mode is active is visible on screen
3. Check that no rewards are granted for completion of the tutorial

## Expected Result

The indicator should be displayed and indicate that tutorial mode is active, with no rewards being granted for its completion.
