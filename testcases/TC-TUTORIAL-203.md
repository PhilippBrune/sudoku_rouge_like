# TC-TUTORIAL-203: Tutorial Should Not Interfere with Other Systems

- **Requirement:** REQ-TUTORIAL-201
- **Type:** Integration
- **Risk:** High
- **Created:** 2026-03-22 13:54:27

## Precondition

User is playing the tutorial mode.

## Steps

1. Start a new game in tutorial mode.
2. Attempt to complete the tutorial without interruption.
3. Try interacting with other systems like path system, XP system or items & relics during tutorial progression.

## Expected Result

The tutorial should not affect normal gameplay loop and tutorial-specific elements like star rating, modifiers etc., should work independently of these systems.
