# TC-UI-001: AccessibilitySettings Configuration Test Case

- **Requirement:** REQ-UI-002
- **Type:** Manual
- **Risk:** High
- **Created:** 2026-03-22 08:52:08

## Precondition

Game is launched without accessibility settings configured

## Steps

1. Navigate to the Settings Menu in the game.
2. Click on "Accessibility".
3. Locate and select "Colorblind Mode" or "High Contrast Mode".
4. Confirm that the selected mode has been successfully applied.

## Expected Result

The Colorblind/ High contrast mode is enabled as expected.
