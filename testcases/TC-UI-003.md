# TC-UI-003: Font Scale Configuration Test Case

- **Requirement:** REQ-UI-005
- **Type:** Manual
- **Risk:** Low
- **Created:** 2026-03-22 08:52:08

## Precondition

Accessibility Settings are configured with a non-default font scale

## Steps

1. Navigate to the Settings Menu in the game.
2. Click on "Accessibility".
3. Adjust the value of "Font Scale" from its current setting.
4. Launch a new game or reload the existing one.

## Expected Result

The font size has increased or decreased as per the new Font Scale setting.
