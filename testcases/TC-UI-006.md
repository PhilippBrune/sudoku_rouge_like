# TC-UI-006: Verify Reduced Motion Enabled/Disabled

- **Requirement:** REQ-UI-006
- **Type:** Manual
- **Risk:** Medium
- **Created:** 2026-03-22 08:52:15

## Precondition

Game is opened with Reduce Motion option disabled by default.

## Steps

1. Open the game.
2. Check if the Reduce Motion option is enabled by default.
3. Toggle the Reduced Motion option on and off.

## Expected Result

When Reduce Motion is enabled, animations should be minimized or disabled entirely. When it's disabled, animations should function as usual.
