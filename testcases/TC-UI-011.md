# TC-UI-011: Check if the user interface is responsive

- **Requirement:** REQ-UI-011
- **Type:** Manual
- **Risk:** High
- **Created:** 2026-03-22 08:52:22

## Precondition

The game and UI are running on a desktop computer

## Steps

1. Open the game application 
2. Ensure that the entire screen is being displayed without any elements missing or cut off.
3. Adjust the resolution of your display to different sizes, and observe if everything still looks good.

## Expected Result

The user interface should be responsive across all screen resolutions
