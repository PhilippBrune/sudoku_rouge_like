# TC-UI-012: Verify if sound effects are working correctly

- **Requirement:** REQ-UI-012
- **Type:** Manual
- **Risk:** Medium
- **Created:** 2026-03-22 08:52:22

## Precondition

User has interacted with the game and played a few rounds of the game

## Steps

1. Start a new game 
2. Interact with various parts of the game (e.g., clicking on buttons, solving sudokus)
3. Listen to the sound effects that are triggered by these interactions

## Expected Result

All sound effects should play as expected when the user interacts with the game
