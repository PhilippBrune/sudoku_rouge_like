# TC-UI-018: Toggle between gameplay modes

- **Requirement:** REQ-UI-018
- **Type:** Manual
- **Risk:** Medium
- **Created:** 2026-03-22 12:37:29

## Precondition

User is logged in and viewing the main menu of the game.

## Steps

1. Click on the "Settings" button.
2. Navigate to the "Gameplay" section.
3. Toggle between "Normal Mode" and "Colorblind-Friendly Mode".
4. Confirm that the text changes appropriately based on the mode selected.

## Expected Result

The game switches to the chosen gameplay mode when toggled, with the correct UI elements being displayed.
