# TC-UI-020: Font scale setting adjusts text size

- **Requirement:** REQ-UI-020
- **Type:** Manual
- **Risk:** Medium
- **Created:** 2026-03-22 12:37:29

## Precondition

User is logged into a game and has selected normal mode.

## Steps

1. Navigate to the "Settings" menu in the main menu.
2. Select the "Graphics" section and find the option for font scale setting.
3. Increase or decrease the value of the font scale by using the slider or text input field provided.
4. Observe how all text elements in the game, including menus and in-game messages, change size as a result.

## Expected Result

The font scaling changes to an acceptable range (0.8–1.5) when adjusted, changing the size of all text elements proportionally.
