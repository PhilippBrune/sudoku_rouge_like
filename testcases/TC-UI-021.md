# TC-UI-021: Reduce motion setting disables animations and particle effects

- **Requirement:** REQ-UI-021
- **Type:** Manual
- **Risk:** Medium
- **Created:** 2026-03-22 12:37:29

## Precondition

User is logged into a game and has selected normal mode, and reduced motion option is not enabled.

## Steps

1. Navigate to the "Settings" menu in the main menu.
2. Select the "Gameplay" section and find the option for "Reduce Motion".
3. Enable the "Reduce Motion" setting.
4. Observe how animations and particle effects have been disabled or reduced in the game.

## Expected Result

Animations and particle effects are either completely disabled or heavily reduced when the "Reduce Motion" option is enabled, improving performance on low-end hardware.
