# TC-UI-022: Colorblind mode setting changes modifier overlays and symbol display

- **Requirement:** REQ-UI-022
- **Type:** Manual
- **Risk:** Medium
- **Created:** 2026-03-22 12:37:29

## Precondition

User is logged into a game, has selected colorblind friendly mode, and reduced motion option is not enabled.

## Steps

1. Navigate to the "Settings" menu in the main menu.
2. Select the "Gameplay" section and find the option for "Colorblind Mode".
3. Enable the "Colorblind Mode" setting.
4. Observe how constraint types are represented visually on the screen, including modifier overlays.

## Expected Result

Appropriate visual representations of constraint types, differentiated symbols, and modified colour of modifier overlays when colorblind mode is enabled, improving visual differentiation for users with color vision deficiencies.
