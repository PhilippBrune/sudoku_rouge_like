# TC-UI-023: Confirmation prompt appears for wrong number placement

- **Requirement:** REQ-UI-023
- **Type:** Manual
- **Risk:** Medium
- **Created:** 2026-03-22 12:37:40

## Precondition

User has placed a wrong number in a cell of the grid

## Steps

1. Click on an empty cell to place a number into it.
2. Enter a number that breaks rules or constraints, such as summing with other numbers.
3. Press enter to confirm placement.

## Expected Result

A confirmation prompt appears for wrong number placement.
