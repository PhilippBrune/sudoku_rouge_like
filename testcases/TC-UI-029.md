# TC-UI-029: Test VisualEfficiency

- **Requirement:** REQ-UI-029
- **Type:** Unit
- **Risk:** Medium
- **Created:** 2026-03-22 12:37:53

## Precondition

The game is open and running on a particular floor

## Steps

1. Open the game and navigate to a specific floor
2. Play the game for a while without checking visual layers in real time
3. Check if active visual layers are below 3 during normal play (including non-critical ones)

## Expected Result

Maximum of 2 non-critical visual layers during gameplay
