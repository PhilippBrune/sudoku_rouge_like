# TC-UI-031: Test MusicSelectionAndStyle

- **Requirement:** REQ-UI-032
- **Type:** Integration
- **Risk:** High
- **Created:** 2026-03-22 12:37:53

## Precondition

The game is open with different music styles and floor theme sounds supported

## Steps

1. Open the game, select a particular music style (e.g., calm, energetic) in settings
2. Play a specific floor and listen to its associated theme sound
3. Switch back to main menu and listen to menu music, check if it matches the selected music style

## Expected Result

Various menu music styles and floor theme sounds for different floors as per the style selected by player are supported and played correctly
