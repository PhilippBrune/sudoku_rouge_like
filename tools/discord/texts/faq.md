# FAQ

**Run of the Nine**

**What platforms is it on?**
Windows, on Steam: https://store.steampowered.com/app/4858470

**Which languages does it support?**
English, German, French, Spanish and Brazilian Portuguese. French, Spanish and Portuguese were translated recently; if a line reads wrong, post it in #rotn-bugs with the tag "Translation".

**Can I play with a controller?**
Yes. Menus, the board and the Options work with a controller; the on-screen number pad enters digits.

**Where are my saves?**
`%USERPROFILE%\AppData\LocalLow\Kratossos\sudoku_rouge_like` (three profile slots). Steam Cloud keeps them in sync.

**A puzzle looks unsolvable. What now?**
Every puzzle has exactly one solution. Post a screenshot in #rotn-bugs with your game version and, if you have it, the run seed (shown in the in-game Options). That helps us check it.

**How do I report a bug?**
One post per bug in #rotn-bugs: what happened, what you expected, the steps, the game version, and a screenshot if you can.

**Corebound**

Questions about Corebound go to #cb-chat; answers will collect here as the game grows.

**How can I help?**
Want to playtest or translate? Say so in #general or in Onboarding; a Moderator will give you the Playtester or Translator role.
